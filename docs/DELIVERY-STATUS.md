# 交付状态与上线条件

此文件按能力区分实际完成状态，避免把测试流程当成真实商业服务。

| 能力 | 当前状态 | 正式使用前剩余条件 |
| --- | --- | --- |
| 商品、购物车、地址、结算、优惠券 | 已实现本地持久化流程 | 真实商品、履约政策、生产数据保护 |
| 购物返积分、签到、积分兑换 | 已实现服务端记账和幂等校验 | 正式积分规则、运营与财务审查 |
| 商家商品、库存、发货、售后审核 | 已实现受控试用工作台 | 生产身份、角色权限、MFA、真实履约 |
| 客户订单搜索、商家 CSV 导出 | 0.4 新增 | 仅受控授权人员可操作；CSV 是敏感业务数据 |
| H5 | 可构建运行 | 域名、HTTPS、生产部署与验收 |
| 微信小程序 | 可编译资源 | AppID、类目资质、合法域名、真机及审核 |
| Android / iOS | 可编译共用资源 | 开发者账号、签名、SDK 真机测试与商店审核 |
| 支付、退款 | 仅测试状态和账务 | 商户签约、网关证书、签名验签、回调重放防护与对账 |
| 穿山甲、微信广告 | 仅内部演示，无广告收入 | 平台审核、广告位 ID、正式 SDK、服务端奖励凭证 |
| 数美 | 未接真实服务 | 合同、密钥、官方协议、数据采集合规与实测 |
| 分享朋友圈奖励 | 未实现 | 平台规则审核；不得伪造分享成功凭证 |
| 生产安全 | 基础保护与自动化测试 | 身份体系、权限细分、依赖整改、渗透及压力测试、恢复演练 |

第三方接入必须依据真实账号、官方 SDK/协议和可验证回调实现，不能用前端按钮成功提示替代。不应把 APP_MODE 改成 production 来绕过限制，当前正式模式拒绝启动。

Windows 预构建包解压后可使用 START-WINDOWS.cmd。该脚本在 Linux 构建环境进行静态检查，未声称完成 Windows 真机验证。服务输出的本机地址只能在运行该服务的电脑访问；宝塔部署遵循 BAOTA.md。
